# Bundled font

`Archivo[wdth,wght].ttf` (variable) is bundled and registered at runtime by
`tink_agent/theme.py` (CoreText), so the themed UI renders without a system
install. Family name once registered: `Archivo`.

Source: github.com/google/fonts (ofl/archivo). License: SIL Open Font License
1.1 — see `OFL-Archivo.txt`.
